- **Business name:** MeriDent. Use the real name only. Do not add keywords such as "Best dental software", because Google can suspend the profile for that.
- **Category (primary):** Software company. Add Computer software company if offered.
- **Address:** Google needs a real address it can verify. If you work from home and customers do not visit, choose "I deliver goods and services to my customers" (service-area business), hide the address and add the cities you serve, such as Coimbatore and Tamil Nadu. Use only an address that is truly yours.
